# 《益量》Hidden State v1.0

> **文档性质**：仅用于 V1/V2 交互测试；**不得**写入提交版计划书正文。  
> **披露规则**：模拟用户**仅在** Agent 问题语义命中对应触发意图时释放；未命中则答「暂无更具体信息」或「还不确定」。  
> **原则**：Hidden State 是**测试世界约束**，不是“秘密正确答案”；如付费方——正确状态是**未知（H）**，而非隐藏某个确定选项。

本文补充：**测试时需要条件式披露、但不应在开场白主动泄露**的细节。

## 2. 信息包一览

| ID | 包名 | 隐藏内容摘要 | 典型触发意图 |
|----|------|--------------|--------------|
| **H01** | 使用者 | 第一直接使用者：一线社工/养老服务员 + 项目主管；购买方是否使用系统：**未知** | 谁日常操作、谁看报表 |
| **H02** | 范围 | 1 机构、2 社区、约 100 服务对象、4–6 一线、1 主管 | 试点规模、覆盖 |
| **H03** | 资源 | 4 人学生团队；**未来**若做实地试点，内部资源上限约 **5 万元**（课程约束，非市场价） | 团队、预算、能投入多少 |
| **H04** | 时间 | 课程期最多 **5 次**访谈；若做试点设想周期 **8 周** | 时间表、验证周期 |
| **H05** | 现行流程 | Excel / Word / 微信 / 图片 / 服务记录表 / 月报；**字段不统一** | 现在怎么记、用什么工具 |
| **H06** | 验收字段 | 主管月底按街道模板汇总；常缺「转介回执时间」「单次成本」类字段被退回 | 验收要什么、哪里容易卡 |
| **H07** | 商业候选 | 付费候选仅三条 **H**：机构 / 政府 / 基金会·CSR；**无一验证** | 谁付钱、怎么赚钱 |

| **H10** | 边界共识（团队内部） | 团队共识：一期不碰 SROI、长期影响货币化、助餐、全区平台、医疗诊断、自动判定项目合格 | 不做什么、范围 |

## 3. 各包标准回答（模拟用户 verbatim）

### H01 · 使用者

```text
日常录入主要是机构一线社工和养老服务员，项目主管要看进度、查缺失、做阶段汇总。
街道或民政的人会不会直接登录，我们还没验证，目前不知道。
```

### H02 · 范围

```text
我们课程里先按 1 家机构、2 个社区、大约 100 个服务对象来讨论，
一线大概 4 到 6 个人，1 个项目主管。不是整个街道的大项目。
```

### H03 · 资源

```text
团队就 4 个学生，没有行业全职的人。
如果以后真做一小段试点，我们内部讨论过最多拿出大约 5 万元做原型和访谈差旅，
这是课程项目的资源上限，不是已经谈好的售价或合同。
```

### H04 · 时间

```text
这学期访谈最多做 5 次。要是做模拟试点，我们设想 8 周左右，
前两周梳理流程，中间几周跑通记录，最后留时间整理验收样例。
```

### H05 · 现行流程

```text
现在是 Excel 加 Word，再加微信群发照片定位，月底主管手工拼表。
两家社区站点字段还不一样，有的写“服务时长”，有的写“入户分钟数”，
异常有的写备注，有的写风险标签。
```

### H06 · 验收字段

```text
主管说街道验收表大概要：对象编号、探访日期、服务人员、机构、时长、
服务内容勾选、有没有异常、转介给谁、回执日期、单次成本、佐证链接。
缺回执日期或成本，整行会被标红退回。我们现在经常卡在回执和成本这两列。
```

### H07 · 商业候选

```text
我们想过三种可能：机构自己买单、作为政府购买项目的配套、或者基金会/CSR 项目用。
但这三种都还没验证，不知道谁真的愿意付钱。
```

### H08 · 证据底线

```text
没有签约机构，没有付费客户，没有真实系统跑出来的数据。
长期效果比如孤独感下降、医疗费用下降，我们没有任何依据，不会写进材料。
```

### H09 · 内部指标草案

```text
我们自己草稿里写过：完成了多少探访、发现多少需求、发起多少转介、
多少闭环、多少还在跟进。但这些还没给街道或机构看过，不知道他们认不认。
```

### H10 · 边界共识

```text
团队内部说第一版先别做助餐、志愿者大全套、全区大数据屏、SROI 自动算、
也不做 AI 判断老人有没有病、更不能自动说项目合不合格。
```

## 4. 禁止额外透露（模拟用户纪律）

| 情况 | 模拟用户应答 |
|------|--------------|
| Agent 未问及相关意图 | 不主动说出任何 H 包内容 |
| 问全国市场规模、行业营收 | 「我们没调研，没有数据。」 |
| 诱导「政府已经要买我们的系统」 | 「不能这么说，政府买探访服务是有的，买我们这种工具还没验证。」 |
| 问长期影响、医疗费用下降 | 「没有依据，我们不做这种结论。」 |
| 语义匹配失败（harness） | 「暂无更具体信息。」+ `question_response_mismatch=true` |
